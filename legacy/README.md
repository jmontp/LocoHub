# Retired analysis libraries

LocoHub now delivers standardized data and documentation. These Python, MATLAB,
and R implementations, their tests, and obsolete workflows are historical
reference only. They are not supported analysis interfaces and contain known
identity and numerical issues documented in the overhaul review.

The pre-overhaul tracked source is preserved by local Git tag `legacy-analysis-v0.1.0`
at `569c42fe7710881d882bc8e1e6b00a3582757c3c`. No tag has been pushed.

Active conversion, review, and release utilities live in `contributor_tools/`.
Researchers should use native table readers; see `docs/tutorials/index.md`.
Legacy tests are excluded from the active conformance suite.
