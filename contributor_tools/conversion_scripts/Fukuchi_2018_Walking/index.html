Fukuchi Walking source adapter

Staged source review; numerical conversion is not implemented. Run python3 source_adapter.py only to inspect the pinned file inventory. This command performs no downloads or conversion.

The files in source_evidence/ are unchanged author-provided documentation, model and processing code, plus Figshare API metadata. Claudiane Fukuchi, Reginaldo Fukuchi and Marcos Duarte are the source authors. Dataset DOI: 10.6084/m9.figshare.5722711.v6. License: CC BY 4.0. File IDs, publisher checksums and local SHA-256 hashes are recorded in candidate.json. No source code was executed.

Paper: Fukuchi et al. (2018), PeerJ 6:e4640. The paper describes 42 participants; version 6 describes 51. Do not silently combine cohorts or versions.
