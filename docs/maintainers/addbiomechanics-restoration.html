Restoring AddBiomechanics sources

The replacement adapter is prepared and fixture-tested. Real source reconstruction has not run. Existing historical files remain unchanged. Source preservation is the first step; anatomical labels and gait events still require separate review.

Files produced by a reviewed run

Each source file gets a source_frames.parquet table, source_metadata.json, and the embedded model XML for each global processing pass. A dataset manifest accounts for every source file and trial, including unfinished work.

The Parquet table contains one raw-frame row and one row for each actual processing pass. source_fields_json holds ordinary JSON with the original field names. Arrays retain their dtype, shape and values. NaN and infinity are represented explicitly; missing values are not evidence of passing. The pass index identifies its slot in that frame, not an assumed global model assignment.

time_s is elapsed time within the source trial, computed from its original frame index and timestep. It does not invent an original session start time. Original B3D files remain the authoritative source and are never deleted or overwritten.

Safe preparation and execution

Use the coordinator’s single-worker schedule. The source adapter requires a fresh output directory and bounded frame reads. A real B3D pilot must pass independent source readback before full reconstruction is scheduled.

For archives, the corrected extractor preserves nested paths and metadata. Its default is preparation only:

python3 contributor_tools/conversion_scripts/AddBiomechanics/extract_source_archive.py \
  --archive /path/to/source.zip --output /path/to/fresh-directory

Use --run only within the reviewed resource-guarded workflow. Do not flatten source directories or delete the original archive.

Checking the saved source tables

The independent auditor rereads the original B3D and compares every saved frame and processing pass, including array shapes, missing values, model XML and trial timing. It does not reuse the exporter’s encoding functions. It is tested with deliberately corrupted examples; real-source readback is still pending.

python3 contributor_tools/conversion_scripts/AddBiomechanics/audit_source_preservation.py --input /path/to/b3d-files --output-root /path/to/source-export --report /path/to/new-readback.json

Run this through the same guarded queue. A successful source check does not establish anatomical labels or gait-event correctness.

Remaining checks

Verify original dataset and participant identity, source version and license, model-specific coordinates, force-body ordering, source mass definitions and quality flags. Trial task labels remain historical mappings unless separately reviewed. Canonical signals and individual gait cycles are not ready merely because source values were preserved.
