This site shows the three datasets being rebuilt now. No dataset on this page is released or approved. The download links in the table are earlier conversions that have not been checked against the original files. Some datasets are being rebuilt; those rebuilt files stay on the maintainer's computer until they are released. Evidence for each dataset.

What the status labels and counts mean
  • Being rebuilt: the data is being rebuilt from the original files now. The page says which problems are known.
  • Local review version (not released): a rebuilt version exists on the maintainer's computer and is being reviewed. It has no scientific approval.
  • Historical count: 150-point curves in an earlier report, labeled with the file it counted. “Full file” means a file with the same name as the Full download; the bytes were not compared. Counts are not participants or verified cycles.

Each label comes from the project task list, not from the page author. No label is scientific approval.
