Collection Details

Protocol

Barefoot overground walking trials processed from C3D marker and force data. OpenSim Scale, IK, and ID pipeline used for kinematics and moments.

Processing Notes

Kinetics are side-conditional on GRF availability: if a side lacks force-plate contact in a stride, that side's moments are stored as NaN (not zero). Use task_info flags (id_has_ipsi_grf / id_has_contra_grf / id_is_bilateral_valid) for filtering.
