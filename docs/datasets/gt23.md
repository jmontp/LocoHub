!!! note "Erratum (2026-10-30): joint moment and power units"
    The publisher README (readme.txt, lines 32-33) states that RawData Joint_Moments.csv is in N·m and Joint_Powers.csv in W. The data show N·m/kg and W/kg. Evidence, 5 seeded random subjects, 8 legs of walking: against a mass-free force-plate lever-arm estimate of the ankle moment in N·m, the source ankle column is smaller by a factor of 64 to 90, a body mass (a column in N·m would give 1; correlation 0.997 or higher); force-plate body masses match the README masses; joint power equals moment times angular velocity (ratio 0.96 to 1.00). ProcessedData is affected too: README lines 18-20 make the same N·m and W claims, and ProcessedData _moment.csv left hip, knee and ankle sagittal values equal RawData Joint_Moments.csv on matched time stamps (3 trials with finite values, checked by an independent verifier; the _moment_filt.csv and _power.csv files were not compared). LocoHub therefore does not divide these moments by mass again. Which mass the authors divided by is not resolved. Audit: `docs/quality/audits/gt23-c02-moment-units.json`.
