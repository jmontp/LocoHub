The full run can produce 1,016 separate leg averages, each interpolated from 101 source points to 150 inclusive phase points. There are no reconstructed cycle durations, stride counts, simultaneous opposite-leg phase or within-person standard deviations.

How the receipt check works

The new completion reviewer reads bounded metadata and hashes file bytes; it does not load whole scientific tables. It rejects changed sources, incomplete file pairs, rewritten readback reports, incorrect participant-condition identities and inflated completion totals. A successful receipt check confirms the evidence chain, not anatomical validity.

Why the paper and archive have different participant counts

The 2018 paper describes 42 participants. The pinned version 6 archive contains 51: 24 younger and 27 older adults. Its published condition coverage is uneven, so the conversion follows the archive inventory instead of inventing a complete grid.

Source: Fukuchi, Fukuchi and Duarte (2018), PeerJ e4640. Dataset version 6 is distributed under CC BY 4.0. No full dataset download is published here yet.
