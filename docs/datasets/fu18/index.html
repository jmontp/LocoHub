Fukuchi Walking

Source reviewed. Conversion has not started. There are no LocoHub files or previews for this dataset yet.

This study covers barefoot overground and treadmill walking at different speeds, with pelvis and leg angles, joint moments and ground reaction forces. The authors also provide raw motion-capture recordings and their Visual3D model and processing pipeline.

What needs checking first

The provided MATLAB example still assumes the older 42-person cohort. Its plots use 101 normalized points, and the processing pipeline exports left- and right-leg windows separately. We must establish whether each table holds individual cycles or averages, and preserve each leg’s real event timing before producing a LocoHub export.

The first pilot will use one recording and matching source events and processed tables. Large archives have not been downloaded. Numerical conversion will wait for the existing dataset work and memory guards.
