Testing & data quality

See what we check, what has actually been tested, and how the phase curves compare with configured limits.

The downloads are still older, unreviewed conversions. Passing software tests means the checking tools behaved as expected on test cases. It does not mean every downloaded curve is correct.

What we check

CheckWhat it catchesWhat it cannot establish
Observation identity and file structureMissing or inconsistent recording/observation IDs, unknown tasks or reference sides, duplicate samples, malformed 150-point phase grids, and invalid time order.Whether the original gait events or limb assignments are scientifically correct.
Missing and invalid signalsRequired versus optional channels; missing, nonfinite, failed and unchecked values stay separate.A missing measurement cannot be recovered by passing another check.
Units, signs and conversionsSmall known examples check joint conventions, force normalization, derivatives and source mappings in supported converters.Every source trial still needs review; some native MATLAB checks are separate or skipped when unavailable.
Phase and waveform boundsConfigured limits at selected phase samples, whole-waveform limits and step-change rules where a profile provides them.A plausible curve is not proof of a valid measurement. Sparse phase checks can miss problems between the checked points.
Rule applicabilityTask, population, condition and observation-type requirements; unmatched or unspecified coverage stays visible.Manually tuned ranges are not universal clinical or physiological norms.
Release files and provenanceSource hash mismatches, inconsistent counts, partial writes, changed releases, and filtering that splits observations.A release build does not create independent scientific approval.
Averages and browser chartsEqual subject weighting, sample SD, singleton SD, missing-value gaps, units, shared axes, and linked static data.Summary curves hide individual variation and combine speeds and conditions within a task.
Memory limits and documentationBounded reads, admission limits, small conversion pilots, example code and local links.Successful tests are not permission to run every large dataset at once.

Inspect phase-range boxes

Choose a dataset, task, subject and signal. Dashed boxes show the configured minimum and maximum at specific phase samples. Their width is only for visibility; it is not a time window. The curve is an average, so a curve inside the boxes does not mean every observation passed.

These are the current manually tuned default ranges, shown for inspection. They may not apply to every population or condition and are not the historical rule snapshot for each download. We do not turn this overlay into a dataset pass/fail score.
